TOPPERS — Premium frontend redesign
===================================
Open index.html in a browser, or use VS Code + Live Server.

Includes a responsive premium homepage, mobile navigation, saved light/dark mode,
About, Courses, Results, Faculty, portal entry cards and an enquiry form.

IMPORTANT: This is a frontend prototype. Portal links are previews, not real login.
It does not securely store student records, passwords, attendance, marks, fees or messages.
Do not enter real student information or passwords. Before client production use, add
a secure backend/database, server-side authentication, role-based access controls,
backups, privacy/security review and verified academy details.

Publishing: Upload this folder to GitHub and import it into Vercel for a public demo URL.
